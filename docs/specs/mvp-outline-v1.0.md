网球约球匹配微信小程序
MVP 需求文档大纲
版本：V1.0  |  测试城市：武汉  |  日期：2026年11月
1. 项目概述
本产品为一款面向网球爱好者的微信小程序，核心目标是帮助用户基于技术等级、时间和球场信息快速匹配球友。
目标用户：网球爱好者（业余至中级为主）
核心价值：降低约球门槛，提升匹配效率与可信度
MVP范围：个人资料 + 发布约球 + 智能推荐 + 匹配确认 + 信用体系
2. 核心匹配规则
2.1 硬性匹配条件（必须同时满足）
技术等级相近：NTRP 相差 ±0.5 以内
时间重合：具体日期 + 具体时段完全一致
同一球场：必须选择相同球场
2.2 软性条件（可选）
性别偏好
年龄偏好
打球风格（单打 / 双打 / 休闲 / 竞技）
2.3 推荐排序规则
信用分高的优先
NTRP 等级更接近的优先
3. 用户资料与等级体系
3.1 个人资料必填字段
微信头像、昵称
NTRP 技术等级（1.0–7.0）
性别、年龄、所在城市
打球风格偏好（单打/双打/休闲/竞技）
个人简介
3.2 等级与互评规则
NTRP 可修改，但有冷却时间（建议每月仅可修改一次）
约球确认到场后，双方可互评（1–5星）
评分仅作参考，不自动修改用户等级
公开展示平均分，不显示具体评分人
4. 场地与城市
测试城市：武汉
内置热门球场数据库，用户仅可选择已有球场，不可新增
注册时选择城市，后续可修改
5. 核心功能流程
5.1 发布约球
用户同时仅能发布一个约球需求
必填：日期、时段、球场、需要人数（单打/双打）
可选：期望对手等级范围、性别偏好
5.2 智能推荐与申请
推荐列表支持上下滑动浏览
卡片展示：头像、昵称、NTRP、信用分、球场、时间、性别
支持筛选：等级范围、性别、时间、球场
申请方点击申请 → 发布方同意 → 匹配成功
5.3 匹配后操作
双方均可取消（记录取消次数）
约定时间后，双方均可点击“已到场”
双方均点击“已到场”后，才可评分并获得信用分
约定时间后24小时无人确认，自动变为“已取消”（不计入取消次数）
6. 信用体系
信用分 = 确认到场次数 - 取消次数（最低为0）
信用分仅作为可信度展示，高信用分用户优先推荐
取消不直接扣分，但会记录次数并影响信用分计算
7. 页面结构
7.1 主要页面
首页 / 推荐列表
发布约球页
约球详情页
我的约球（待确认 / 已确认 / 已完成 / 已取消）
个人中心（我发布的 / 我申请的 / 已匹配成功的）
个人资料编辑页
8. MVP 明确范围
8.1 MVP 包含
微信登录 + 个人资料
发布约球 + 智能推荐 + 申请匹配
确认到场 + 星级评分 + 信用分
我的约球状态管理
8.2 MVP 不包含
聊天 / 即时沟通功能
消息推送通知
拉黑 / 举报功能
用户新增球场
自动调整 NTRP 等级
